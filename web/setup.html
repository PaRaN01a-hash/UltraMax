Step 04
🚀 Finalise / Generate
HOW FINALISE WORKS
▾

Finalise saves the setup you have just built and generates the Ultra MAX add-on you will actually use.

1. Review before generating

Check the summary and install-status card. They reflect the current catalogs, collections and settings from Steps 1–3.

2. Generate Final Setup

Generate saves your latest configuration and creates or updates its Ultra MAX add-on URL.

Generating does not automatically mean you need to reinstall the add-on.

3. Follow the install status

If this is a first install or a reinstall is required, Ultra MAX will tell you. Otherwise a normal app refresh or restart is enough.

Collections are already configured in Step 3 and are not rebuilt separately here.

4. Install in Nuvio — Optional

If Nuvio is connected, choose the profiles that should receive the generated Ultra MAX add-on.

You can also copy the add-on URL and install it yourself in Nuvio or Stremio.

5. Save your token and password

Your setup token is how you reopen this configuration later.

Keep the token and setup password somewhere safe so you can return and edit it.

6. Recovery email — Optional

You can add a recovery email so a lost setup token can be recovered.

It is optional and is not used for marketing.

7. Extra tools are optional

Device Profiles create alternate versions for different devices.

Project File and Catalog CSV are export tools and are not required to finish.

Collection preview and sync stay in Step 3, where the collections are built.

For most returning setups: review → generate → follow the install-status card. Nothing else is required unless Ultra MAX tells you it is.
