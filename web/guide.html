ULTRA MAX
SETUP GUIDE

A complete reference for setting up and configuring Ultra MAX — from your first API key to a fully personalised home screen in Stremio and Nuvio.

📺 Stremio & Nuvio compatible
⚡ Free — no account required
🕐 ~10 minutes to complete
What is Ultra MAX?
Understanding what you're installing and how it works

Ultra MAX is a free, self-hosted catalog addon for Stremio and Nuvio. It provides a fully personalised home screen with over 240 catalog rows — covering trending content, streaming providers, genres, studios, decades, actor filmographies, director collections, MDBList curated lists, and more.

Everything runs on Ultra MAX's own servers. You do not need to host anything yourself — simply complete the setup wizard, copy your personal addon URL, and install it into Stremio or Nuvio. Your configuration is tied to a personal token that only you have access to.

ℹ Ultra MAX is not a streaming source. It organises and presents content metadata from TMDB and MDBList. You still need your own streaming addons (such as a debrid service) to actually watch content.

How it works

When you complete the setup wizard, Ultra MAX generates a personalised manifest URL. This URL tells Stremio or Nuvio which catalog rows to show on your home screen and in what order. The manifest updates automatically when you make changes to your setup — you do not need to reinstall after every change.

Prerequisites
What you need before you begin

Required

1
Stremio or Nuvio installed
Ultra MAX works with both Stremio (stremio.com) and Nuvio (nuvio.tv). You need at least one of these installed on your device before you can install the addon. Nuvio users get additional features including native collections support and one-click profile push.
2
A free MDBList account and API key
MDBList powers the majority of Ultra MAX's curated catalog rows — trending lists, top-rated charts, and genre collections. Registration is free at mdblist.com. Your API key is found under Settings → API.
3
A TMDB API Read Access Token
TMDB provides all poster images, metadata, actor filmographies, and studio catalogs. Create a free account at themoviedb.org, then go to Settings → API and copy the long API Read Access Token (starts with eyJ). Do not use the short API key — it will not work.

Optional but recommended

Optional
Trakt account
Enables personal rows (watchlist, favourites, collection), hide watched titles, and AI recommendations based on your viewing history.
Optional
Simkl account
Alternative to Trakt. Syncs your Simkl plan-to-watch list and feeds AI recommendation rows.
Optional
RPDB API key
Enables rated poster overlays — posters with IMDb, TMDB, or AniList rating badges displayed on top. Free tier available at ratingposterdb.com.
Optional
Google Gemini API key
Powers the AI recommendation rows. Analyses your Trakt or Simkl history to generate two personalised rows — one for movies, one for series. Free tier available.
01
Obtaining Your API Keys
Step-by-step instructions for MDBList and TMDB

MDBList API Key

1
Create a free account
Go to mdblist.com and register. The free tier is sufficient — you do not need a paid subscription for Ultra MAX.
2
Find your API key
Once logged in, click your profile icon → Settings → scroll to the API section. Copy the key shown there.
3
Verify in the setup wizard
Paste the key into the MDBList field in Step 1 of the wizard and click Check. Your MDBList username should appear if the key is valid.

TMDB API Read Access Token

⚠ TMDB provides two credentials on the same page — a short API Key and a long API Read Access Token. Ultra MAX requires the Read Access Token (the long one starting with eyJ). Using the short API key will cause verification to fail.
1
Create a free TMDB account
Go to themoviedb.org and register. Account creation is free.
2
Request API access
Navigate to Settings → API from your profile menu. If you have not already requested API access, you will need to do so — select Developer and fill in the brief form. Approval is usually instant.
3
Copy the Read Access Token
On the API settings page, find the API Read Access Token field (the long one, not the short API Key above it). Copy the entire token.
02
The Setup Wizard
A walkthrough of all four steps

The setup wizard at ultramax.vip/setup guides you through four steps. You can return at any time to edit your setup using your personal token.

Step 1 — Setup

Step 1 covers the essentials: your API keys, optional integrations, content filters, and language preferences.

  • Password — set a password to protect your setup. Keep a note of this — you will need it to load your setup in future.
  • MDBList API key — required. Enter and verify before continuing.
  • TMDB API Read Access Token — required. Enter the long token starting with eyJ.
  • Trakt / Simkl — optional. Click the respective connect button to link your account via OAuth. This never shares your password with Ultra MAX.
  • Poster Providers — optional. Enter an RPDB key for rated poster overlays.
  • AI Recommendations — optional. Select a provider (Google Gemini recommended) and enter an API key to enable personalised AI rows.
  • Language — sets the metadata language for all catalogs. Does not affect content availability, only how titles and descriptions are displayed.

Step 2 — Home Rows

Step 2 is where you choose which catalog rows appear on your home screen. Rows are grouped by category — streaming providers, genres, studios, decades, networks, and more.

  • Use the preset buttons at the top to start with a sensible default selection, then customise from there.
  • Rows can be reordered by dragging them within the interface.
  • Toggle rows on or off individually using the eye icon on each row.
  • The live preview panel on the right shows an approximation of how your home screen will look in Nuvio.
  • Aim for 20–50 rows for good performance. Very large selections (100+) may result in slower catalog loading.
💡 Actor and director rows are available in the People section. Each adds a filmography row to your home screen showing that person's movies or series.

Step 3 — Collections

Collections are Nuvio-native folder structures that group your home rows into categories — for example a "Streaming" folder containing Netflix, Prime, and Disney+, or a "Decades" folder with rows for each decade.

  • Use the preset collections to start with a curated structure.
  • Collections can be renamed, reordered, and customised.
  • This step is Nuvio-specific. Stremio users can skip it — all rows are installed flat.
  • The Community Gallery at ultramax.vip/gallery contains collections shared by other users that you can download and import.

Step 4 — Finalize

Step 4 generates your final configuration and provides two things you need to install Ultra MAX:

  • Addon URL — your personal manifest URL. Install this into Stremio or Nuvio to add all your selected home rows.
  • Nuvio Collections JSON — a separate file for Nuvio users that sets up your folder structure. Download and import it in Nuvio → Collections.
ℹ Your token is displayed in Step 4. Save it somewhere safe — it is the key to loading your existing setup in future. If you lose it and registered an email address, you can recover it at ultramax.vip/recover.
03
Installing Ultra MAX
Adding the addon to Stremio or Nuvio

Stremio

1
Copy your addon URL from Step 4
The URL follows the format shown below. It is unique to your configuration.
2
Open Stremio → Addons → Community addons
Paste your URL into the search field at the top of the addons page and press enter.
3
Click Install
Ultra MAX will appear as an installed addon. Your home screen rows will appear immediately.
Your addon URL format
https://ultramax.vip/c/YOUR_TOKEN/manifest.json

Replace YOUR_TOKEN with the token shown in Step 4 of the wizard.

Nuvio

1
Install the addon URL
In Nuvio, go to Settings → Streams → Addon URLs. Paste your Ultra MAX addon URL and tap Import.
2
Import your Collections JSON (recommended)
Download the Nuvio Collections JSON from Step 4 of the wizard. In Nuvio, go to Collections → Import and select the downloaded file. This sets up your folder structure.
3
Or use one-click push (optional)
If you link your Nuvio account in Step 4, you can push your entire setup directly to a Nuvio profile in one click — no manual file import needed.

Re-installing after changes

Your addon URL does not change when you update your setup. Changes to your selected rows take effect automatically within a few minutes. You only need to re-install if you are adding Ultra MAX to a new device.

If you update your collections in Step 3, you will need to re-import the Nuvio Collections JSON file to update the folder structure in Nuvio.

04
Optional Features
Integrations that enhance your experience

Trakt Integration

Connecting Trakt unlocks several additional features:

  • Personal rows — your Trakt watchlist, favourites, and collection appear as catalog rows.
  • Hide watched titles — movies and series you have watched are automatically filtered from all catalog rows.
  • AI recommendations — your viewing history is used to generate personalised movie and series recommendation rows.

Connect Trakt in Step 1 of the wizard by clicking Connect Trakt. You will be redirected to Trakt to authorise the connection — your Trakt password is never shared with Ultra MAX.

Simkl Integration

Simkl provides similar functionality to Trakt. Connect it in Step 1 via Connect Simkl. You can use both Trakt and Simkl simultaneously — Ultra MAX will merge data from both sources.

BetterPosters

BetterPosters overlays rating badges on poster images, showing scores from IMDb, TMDB, AniList, and other sources. Configure it in the Poster Providers section of Step 1. Select your preferred rating source and style.

AI Recommendation Rows

When enabled, Ultra MAX generates two additional rows — AI Movies for You and AI Series for You — based on your Trakt or Simkl watch history. Requires a Gemini API key (free tier available at aistudio.google.com).

💡 AI rows are regenerated periodically. If the recommendations look stale, load your setup and save it again to trigger a refresh.
05
Content Filters
Controlling what appears in your catalogs
🚫
Hide Unreleased Titles
Removes titles that have not yet been released. Applies across all catalog rows, search, and actor filmographies. Recommended for most users.
🎬
Digital Release Only
Only shows movies once a confirmed digital, physical, or TV release date has passed on TMDB. A good signal that a quality stream exists. Does not affect series.
👁
Hide Watched Titles
Requires Trakt or Simkl. Filters out content you have already watched from all catalog rows. Movies are hidden if any watched entry exists; series only if fully completed.
🌍
Language & Country Filters
Restrict catalog rows by origin country or exclude specific languages. Useful for filtering out K-dramas, anime, or other regional content you do not want to see.
06
Stream Badges
Customising stream information display in Nuvio

Stream badges are small visual indicators that appear next to each stream in Nuvio's stream list, showing information such as resolution, codec, audio format, and streaming source. Ultra MAX hosts a collection of community badge packs and a visual builder to create your own.

Using an existing badge pack

1
Browse packs at ultramax.vip/badges
The badges page lists all available packs with live previews. Find one you like and click Copy URL.
2
Add it to Nuvio
In Nuvio, go to Settings → Streams → Fusion Badge URLs (TV) or Settings → Streams → Badge URLs (Mobile). Paste the URL and tap Import. You can add up to three badge packs simultaneously.

Building a custom badge pack

The Badge Builder at ultramax.vip/badge-builder allows you to mix and match badges from multiple packs, toggle individual badges on or off, reorder them, edit colors and patterns, and download a custom JSON pack to host yourself.

📱 Nuvio Mobile
📺 Nuvio TV

Stream badges are a Nuvio-exclusive feature. They do not appear in Stremio.

07
Android App
The dedicated Ultra MAX companion app

The Ultra MAX Android app provides a native mobile and Android TV interface for accessing the setup wizard, managing your configuration, linking accounts, and checking for updates. It is separate from the addon itself — you do not need the app to use Ultra MAX, but it provides a more convenient experience on Android devices.

Downloading the app

Download
ultramax.vip/downloads

Direct APK download. Enable "Install from unknown sources" in your Android settings if prompted.

App features

  • Setup wizard access — full access to all four setup steps within the app.
  • OAuth deep linking — Trakt and Simkl OAuth flows open within the app and return you automatically after authentication.
  • In-app update checker — the app notifies you when a new version is available and provides a direct download link.
  • Android TV support — the app is compatible with Android TV and Fire Stick devices with D-pad navigation support.
💡 On Android TV, navigate to the app using your remote. D-pad navigation is fully supported throughout the setup wizard and all main sections.
Managing Your Setup
Tokens, passwords, and loading existing configurations

Your token

Your token is an 8-character code that identifies your configuration. It is displayed in Step 4 of the wizard and forms part of your addon URL. Keep it somewhere safe.

ultramax.vip/setup?token=YOURTOKEN Load existing setup

Loading an existing setup

To edit your setup at any time, go to ultramax.vip/setup and click Load Existing Setup. Enter your token and password. Your previous configuration will be loaded and you can make changes.

Passwords

A password is set in Step 1 to protect your configuration. If you forget your password:

  • On the token login screen, click Forgot password? to access the inline reset form.
  • Enter a new password and confirm it. The reset takes effect immediately.
  • If you have also lost your token, go to ultramax.vip/recover and enter your registered email address to have your token sent to you.

Registering an email address

In Step 4 of the wizard, you can optionally register an email address against your token. This is used solely for token recovery — it is never used for marketing or shared with third parties.

Multiple profiles

Ultra MAX supports device profiles — separate configurations within the same token, each with its own addon URL. This allows you to maintain different home screen setups for different devices (for example, a 4K TV setup and a mobile setup) without managing multiple tokens.

Profiles are created in Step 4 under Device Profiles.

Troubleshooting
Common issues and how to resolve them
My catalog rows are showing but empty ▼
Empty rows are most often caused by an invalid MDBList or TMDB key. Go back to Step 1 and verify both keys are accepted. Also check your content filters — Hide Unreleased Titles and Digital Release Only can reduce results significantly for newer content.
My TMDB key fails verification ▼
The most common cause is pasting the short TMDB API Key instead of the long API Read Access Token. The correct token starts with eyJ and is several hundred characters long. On the TMDB API settings page, look for the field labelled "API Read Access Token (v4 auth)".
Token not found when trying to load my setup ▼
Check you are entering the token exactly as shown — tokens are 8 characters and case-sensitive. If you have lost your token entirely, use the recovery page at ultramax.vip/recover to have it sent to your registered email address. If you did not register an email, contact support via the subreddit.
Trakt or Simkl connection shows as failed ▼
Trakt and Simkl tokens expire after a period of inactivity. Go to Step 1, disconnect the integration, and reconnect it. This generates a fresh token. If the issue persists, check that you have not revoked Ultra MAX's access in your Trakt or Simkl account settings.
Collections show "Addon not found: com.ultramax" in Nuvio ▼
This means the Ultra MAX addon is not installed in the Nuvio profile where you imported the collection. Install your addon URL in Nuvio first (Settings → Streams → Addon URLs), then import the collection. Both must be in the same profile.
Home screen rows are not updating after I made changes ▼
Changes to your setup take effect within a few minutes as the manifest cache refreshes. If rows still appear incorrect after 5 minutes, force a refresh in Stremio by going to your addon settings and tapping the refresh button. In Nuvio, a full app restart usually resolves the issue.
The AI rows show generic recommendations, not personalised ones ▼
AI rows require a connected Trakt or Simkl account with meaningful watch history. Accounts with fewer than 20 watched titles may receive generic recommendations. Additionally, ensure your Gemini API key is valid and that the AI Recommendations toggle is enabled in Step 1.
Posters are not showing rating overlays ▼
Rated poster overlays require a valid RPDB key entered in Step 1 under Poster Providers. Verify the key is correctly entered. Free-tier RPDB keys have a daily request limit — if overlays disappear mid-session you may have reached it. Also check that BetterPosters is enabled and the correct rating source is selected.
💬 Still stuck? The Ultra MAX community on Reddit at r/Ultra_Max is active and can help with most issues. When asking for help, include your token (it is safe to share) so the issue can be investigated directly.
